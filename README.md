# ML_Tumor-Progression-Prediction
The goal of this project is to build a binary classification model that predicts whether a tumor is malignant (M) or benign (B) based on a range of digitized features computed from a breast mass's cell nuclei in digitized fine needle aspirate (FNA) images.
